CSL sources used by the local article generator

Styles and locales are vendored from the Citation Style Language project:
https://github.com/citation-style-language/styles
https://github.com/citation-style-language/locales

Each XML/CSL file includes its own attribution and license information.
Styles were downloaded on 2026-10-31. The original styles matching the OJS menu
that have since been removed or renamed were recovered from these commits:

- acs-nano: d26b39a07db6d147acd697037624d9461bb350e0
- turabian-fullnote-bibliography: 2833b5d5d519be882e5bf7229776ee5decba9d5a
- vancouver: 5e762f49be0ff19290160a08bfe0202c7d5d729d

The remaining styles and the en-US/pt-BR locales were downloaded from master.
Generation uses these local files and makes no network requests.
